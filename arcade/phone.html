100% pocket lock (iPhone, optional)
  1. Once: Settings → Accessibility → Guided Access on, and in it Display Auto-Lock → Never
  2. Here, after Start sensing: triple-click the side button → Options → Touch off and Side Button off → Start
  3. Done playing: triple-click the side button and enter your passcode

Built into iOS: no touch, no button and no sleep can stop the sensing. On Android the same is App pinning (Settings → Security).
